# 💼 MyProfile для предпринимателей

![Status](https://img.shields.io/badge/Status-Completed-success.svg)
![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

Консольное интерактивное приложение на Python, предназначенное для сбора, валидации, структурированного хранения и форматированного отображения данных индивидуального предпринимателя (личных и банковских реквизитов).

---

## 📌 Основные возможности

- **Ввод и редактирование личных данных:**
  - Имя, возраст, email, адрес и заметки.
  - Автоматическая очистка номера телефона от лишних символов (остаются только цифры и знак `+`).
  - Очистка почтового индекса от нечисловых символов.
- **Ввод и учет данных предпринимателя:**
  - ОГРНИП, ИНН, Расчетный счет (Р/с), Корреспондентский счет (К/с), БИК и Наименование банка.
- **Встроенная валидация данных:**
  - Проверка возраста (не может быть отрицательным).
  - Склонение слова «год/года/лет» в зависимости от введенного возраста.
  - Проверка длины ОГРНИП (строго 15 знаков).
  - Проверка длины расчетного счета (строго 20 знаков).
- **Гибкий вывод информации:**
  - Просмотр только личных данных.
  - Просмотр полной карточки предпринимателя (личные данные + реквизиты).
